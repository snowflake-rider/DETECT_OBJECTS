# Audio output test sample

`cat_meow.wav` is the short fixture played by the device-setup audio output
probe. It was converted to 16-bit, 16 kHz, mono PCM WAV from
[Meow of a pleading cat](https://commons.wikimedia.org/wiki/File:Meow_of_a_pleading_cat.oga)
by Heismark, released to the public domain.
