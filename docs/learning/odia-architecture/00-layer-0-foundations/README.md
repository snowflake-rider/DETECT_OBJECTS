# Layer 0 — Foundations

Layer 0 gives you a simple map of the whole application.

After this layer, you should be able to explain:

- where the main code lives;
- what `python -m detect_objects` starts;
- what happens before the camera begins;
- why the project has a `Context` and a `LocalRuntime`;
- what happens when the program closes.

next lesson.

go through them one at a time. Layer 1 starts only after you clear Layer 0.
