# Learn the ODIA architecture

This directory teaches how the project is organized and how one run moves
through the code.

You do not need to memorize every file. The goal is to understand the main
path first, then add detail one layer at a time.

## Learning layers

- **Layer 0 — Foundations:** project folders, entry point, and main workflow.
- **Layer 1 — Modules and data flow:** how voice, camera, and shared data work.
- **Layer 2 — Runtime design:** threads, events, queues, and distributed nodes.

Only Layer 0 exists for now. We will add the other layers later.

## Start here

Read [Layer 0 — Foundations](00-layer-0-foundations/README.md) in order.

For each lesson:

1. Read the short explanation.
2. Open the source files named in the lesson.
3. Explain the flow aloud using your own words.
4. Answer the layer's questions one at a time.

Each layer has one `QUESTIONS.md` file. We mark a layer as cleared only after
you understand every question. New layers are added only when you request
them.
